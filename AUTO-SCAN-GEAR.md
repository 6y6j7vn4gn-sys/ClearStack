## 1. Machines that scan automatically (ADF duplex)

Sheet-fed, **automatic document feeder**, **duplex** (both sides) — page-by-page without flipping by hand. Buy only in Stage 1+.

| Machine | Role for ClearStack | Notes |
|---------|---------------------|-------|
| **Ricoh ScanSnap iX2500** | **Recommend after first cash** | Current flagship small-office workhorse · Wi-Fi · duplex ADF · pairs with ScanSnap Home · best default buy |
| **ScanSnap iX1600 / iX1300** | Strong used/sale alternatives | Same family; fine if price is better on sale — still duplex ADF |
| **Brother ADS series** | Budget duplex ADF | Consider if cheaper on sale and duty cycle fits mid packages |
| **Epson DS-870 / DS-970** | Higher-volume workhorse class | When page throughput climbs past ScanSnap comfort |
| **Fujitsu fi-8170 class** | Production / bureau-adjacent | Later — when recurring volume and QA justify production scanners |

**Day One–90 reality:** ClearStack wins on **fixed-scope searchable books**, not Iron Mountain fleets. One good ScanSnap after first invoice beats an empty floor of production gear.

**Not Day One buys:** Wide-format / blueprint plotters — partner or outsource sheets; package into the client book.

## 2. Stage 0 apps (manual) — Operator uses these NOW

No ADF required. Even light · steady hands · aim for **~300 DPI feel**. Capture → `CS-INBOX` → Money Maker OCR/name/index → Operator QA → deliver.

| App | Platform | Use |
|-----|----------|-----|
| **iOS Notes / Files scanner** | iPhone / iPad | Primary Day One capture — fast, clean edges, multi-page PDF |
| **Adobe Scan** | iOS / Android | Strong edge detect + OCR assist; good for mixed stacks |
| **Microsoft Lens** | iOS / Android | Whiteboard/docs modes; solid for forms and receipts |
| **Google Drive scan** | Mobile Drive app | Scan straight into Drive folder for Man×Machine handoff |

**Also in the stack (already owned):** iPad (primary capture + Zoom) · Samsung tablet (parallel / review) · phone (overflow / photo→PDF add-on).

**Operator NOW:** Sell and scan with these apps. Do not wait on hardware to quote or deliver Stage 0 packages.

## 3. Software (OCR / packet build)

| Tool | When | Why |
|------|------|-----|
| **ScanSnap Home** | With ScanSnap purchase | Native duplex pipeline, profiles, Wi-Fi batch to PC |
| **ABBYY FineReader PDF** | Stage 1 — messy paper | Best-in-class OCR accuracy for real-world stacks (gold standard) |
| **Adobe Acrobat Pro** | Stage 0–1 if subscribed | Merge, OCR, redact, bookmarks — daily edit path; “good enough” OCR for clean pages |
| **VueScan** | Optional | Extra driver/format control for odd scanners or archival TIFF needs |

**Free / backup OCR path:** Microsoft OneNote OCR · Google Drive upload OCR · Tesseract on the box (Money Maker) — keep as fallback so Stage 0 never stalls.

**Delivery standard (every book):** Searchable OCR PDF · consistent file names · bookmarks/TOC · page count · batch ID `CS-…`

## 4. Man × Machine flow (gear-aware)

```
CLIENT → ship / drop / upload
   ↓
OPERATOR (Stage 0 apps  →  later ScanSnap ADF duplex)
   ↓  CS-INBOX batch
MONEY MAKER — OCR · name · index · QA list · searchable book
   ↓
OPERATOR — final QA · secure link (+ optional USB) · return vs dispose ask
```

| Step | Stage 0 | Stage 1+ |
|------|---------|----------|
| Capture | Notes / Files / Adobe Scan / Lens / Drive | ScanSnap ADF duplex (+ apps for odd sizes/photos) |
| OCR / book | Acrobat / Drive / FineReader when ready · Money Maker pipeline | ScanSnap Home → FineReader / Acrobat → Money Maker QA |
| Specialty / oversize | Photo + partner sheets | Same — don’t buy wide-format yet |
