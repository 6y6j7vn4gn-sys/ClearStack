## 2. How we advertise (organic / low-cash)

### Cash rule
**Zero paid ads until first invoice.** No Google Ads, Meta boosts, or sponsored LinkedIn until a paying ClearStack deposit clears. Then reassess — organic still leads.

### Channel stack (in order of conversion)

| Priority | Channel | Tactic |
|----------|---------|--------|
| **1** | **Warm network** | Highest conversion. Ex-colleagues, contractor breakfasts, church/community admins, TRL/ABC contacts. Script: *“Approximate page count? Fixed ClearStack package — searchable PDF + index. 50% to start.”* |
| **2** | **Google Business Profile (organic)** | Category: Document scanning service. Service-area business (hide home address). Services = ClearStack packages. Photos: process + redacted before/after. Weekly posts. Ask every paying client for a review. **Keywords:** document scanning Upland / Ontario / Rancho Cucamonga / paper to PDF / searchable PDF |
| **3** | **LinkedIn (organic)** | Company page + operator posts: before/after stack→packet (sanitized), “box of leases → searchable PDF,” plan-set tips. Target titles above. Connect → short page-count ask (not a pitch-deck dump). **No personal legal names on public creatives.** |
| **4** | **Partnerships** | Shred-only vendors, movers, office organizers, bookkeepers, RE transaction coordinators, UPS/FedEx overflow, blueprint bureaus (letter-size remainder). Referral fee or reciprocal **after first invoice** if needed. |
| **5** | **Cold-light email / LinkedIn** | 5–10/day max. ClearStack brand. Personalize by segment. No purchased mega-lists. |
| **6** | **Chambers / associations** | Upland, Ontario, RC, Fontana chambers; ABC SoCal; HOA vendor lists; realtor associations. Leave-behind one-pager. Lunch-and-learn: “From binder to searchable packet in a week.” |

### Do not waste Day One on
- Federal RFP portals without past performance  
- Competing My ScanTeam / Scandoc on **cents per page**  
- HIPAA-certified hospital RFPs without real posture  
- Paid ads before first invoice

## 4. First-client messaging lock

### Core promise
We don’t just “scan.” We build **searchable digital books**:
- OCR so clients can **Ctrl+F / search** inside the PDF  
- Named files + bookmarks / index (a real book, not a dump of images)  
- **All common form types:** letter, legal, invoices, applications, HR forms, receipts (batched), statements, contracts, mixed binders, photos-to-PDF add-on; color or B&W to match originals  
- Specialty (blueprints / fragile) = quoted / partner — still packaged into the book  

**One-liner:** *Messy stack in → searchable digital book out.*

### Hunt script (outreach + GBP + LinkedIn)
*ClearStack turns every binder and form type into a **searchable digital book** — not a pile of pictures. You ship a box, drop off by appointment, or upload. We return a link (and optional flash drive). You choose: paper returned or securely disposed after you approve.*

### Segment openers (ClearStack only)
**Property / HOA** — Subject: Lease boxes → searchable PDFs (Upland / IE)  
*ClearStack turns closed lease / vendor boxes into a fixed-scope OCR PDF package so your team stops digging through filing rooms. Local IE. Reply with approx. box count for a same-week scope.*

**GC / PM** — Subject: Plan sets + project file package  
*ClearStack packages blueprints and closeout paper into clean, shareable PDFs — without copy-shop chaos. Send sheet count or photo of the stack.*

**Title / escrow / small law (admin)** — Subject: Closed-file room → searchable packet  
*ClearStack digitizes closed escrow/matter boxes into organized searchable PDFs. Fixed scope. Ideal before an office move or audit. Box count = quote.*

**Office manager (generic)**  
*Drowning in paper archives? ClearStack returns a named, searchable PDF packet — not a random scan dump. Reply with rough page count for a same-day quote.*

### Delivery ask (always)
After they approve the digital book: **return originals** · **secure dispose/shred via partner** · or **hold 14 days then dispose** if no reply. Never shred before written OK.

## 5. Week-1 advertising cadence

1. List ~20 warm + sweet-spot names (GCs, PMs, office mgrs, HOA/property, 2 churches)  
2. Send **5 ClearStack page-count asks**  
3. GBP draft ready (service-area, packages, keywords)  
4. One redacted sample searchable book for Zoom  
5. Partner text to 1 bookkeeper + 1 shred/print overflow  
6. LinkedIn: 1 operator post (sanitized before/after) + 3 title connects  
7. First deposit → Accounting `CS-` invoice · **still zero paid ads until that invoice**

### Success metrics
- 5 outreach / day (when ClearStack block is on)  
- 1 quote / day target  
- 1 sample packet in portfolio  
- First paid CS- deposit
