Job Machine Dual Plan A

Dual Plan A = two cash machines in one day, in a fixed order: job apps first, then one ClearStack unlock. Never flip the order when mortgage pressure is high.

Spell the words

  • Dual Plan A = weekday rhythm: Job Machine block, then ClearStack inch — same quotas if you start late (slide, don’t shrink).
  • Job Machine = the teammate agent that owns Indeed / LinkedIn / USAJobs / company portals. Target: well-paid engineering (~$115k–140k+). You still click Apply and clear sign-in walls.
  • ClearStack inch = one soft-live unlock after apps (for example: rent PMB, retrieve EIN digits, Upland license FILE IT, Chase/Zelle, GBP LIVE).
  • Quota = measurable result, not hours. Apps quota is ≥3 submitted / day. ClearStack quota is ≥1 real rail inch.
  • Soft-live = Friday Sep 11 bar: same-day quote + ClearStack Zelle deposit path + SEND out + PMB intake + GBP live — still draft-only until you write FILE IT / BUY IT / GBP LIVE.

The clock (Pacific)

Weekdays: 9:00–12:00 = apps (≥3) · 1:00–3:00 = ClearStack inch.

Sunday: clock-in 1:00 PM · apps first (~1:15–3:30) · then one ClearStack inch.

Late start: slide the same blocks later. Quotas stay. Do not cut apps to “catch ClearStack.”

Why apps come first

  • October mortgage (~$20k) needs the fastest probable cash path — W2 apps are Plan A bridge; ClearStack invoices are the own-business door.
  • ClearStack storefront is already live — the bottleneck is rails (PMB #, EIN PDF, Chase Zelle, GBP), not more polish.
  • Protect the $400 cash floor. Soft-live spend stays tiny (B/E lanes only).

Who does what

YOU (Operator)

  • Submit ≥3 apps (click Apply · Cloudflare · Login.gov)
  • One ClearStack body trip / bank step when ready (PMB ### · FILE IT)
  • Reply apps N · FILE IT · PMB ### · GBP LIVE
  • Keep one money focus per block (ADHD rule)

ME (Money Maker) + Job Machine

  • Job Machine: shortlist, resumes, portal prep for apps
  • Money Maker: ClearStack drafts, site, quotes, honest scoreboard
  • Never invent apps / SEND / deposits
  • Ask you only for final send / FILE IT / BUY IT
