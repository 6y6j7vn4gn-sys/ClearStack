Intake rails — Inbox, PMB, quote → deposit

Paper and money never go to your house porch. They enter through Inbox (email), PMB (Private Mail Box), and a clear quote → 50% deposit before we open a box.

Spell the rails

  • Inbox = business email clients use (target hello@ after domain). Status Tue Sep 8: not created yet — public contact is Hotmail for now.
  • PMB (Private Mail Box) = your box number at The UPS Store — commercial street address, not 371 D St. Locked store: 1042 N Mountain Ave Ste B, Upland. Status: address chosen · box # not rented.
  • Quote = package price from the live table ($89 / $169 / $299 / $399).
  • Deposit = 50% before we receive paper or start the searchable book. Cards = full 50% of list. Zelle = −15% off package, then 50% of that discounted total.
  • CS-ID (ClearStack Job ID) = code like CS-20260908-01 on every quote, Zelle memo, and shipping label.
  • EIN (Employer Identification Number) = IRS business tax ID. Done as sole prop ClearStack · digits/PDF still missing (blocks Chase).

The money path (quote → deposit)

  1. Client asks (form / reply) with page estimate or stack size.
  2. We reply with package price + CS-ID + pay options (Square/Stripe card or ClearStack Zelle when live).
  3. Client pays 50% deposit — memo must include CS-ID.
  4. Only then we share intake (PMB / prepaid UPS kit / pickup) — never put 371 D St on the public site.
  5. Receipt when materials arrive · build searchable book · balance on delivery.
