Intake rails — Inbox, PMB, quote → deposit

Paper and money never go to your house porch. They enter through Inbox (email), PMB (Private Mail Box), and a clear quote → 50% deposit before we open a box.

Spell the rails

  • Inbox = business email clients use (target: hello@ / ClearStack Gmail). Status today: not created yet.
  • PMB (Private Mail Box) = your box number at The UPS Store — commercial street address, not 371 D St. Locked store: 1042 N Mountain Ave Ste B, Upland. Status: address chosen · box # not rented.
  • Quote = page-band package price from the live table ($99 / $179 / $249).
  • Deposit = 50% before we receive paper or start the searchable book. Cards = full 50%. Zelle = $50 intake courtesy only when deposit > $50 (so ≤50 / $99 = full ~$49.50 — no courtesy).
  • CS-ID (ClearStack Job ID) = code like CS-20260907-01 on every quote, Zelle memo, and shipping label.

The money path (quote → deposit)

  1. Client asks (form / reply) with page estimate or stack size.
  2. We reply with package price + CS-ID + pay options (Stripe card or Zelle when live).
  3. Client pays 50% deposit — memo must include CS-ID.
  4. Only then we share intake address (PMB) or upload link — never on the public homepage as a home address.
  5. Receipt email when materials arrive · build searchable book · balance on delivery.

Who does what

YOU (Operator)

  • Create Inbox when ready (final-send)
  • Rent PMB in person (2 IDs) · text Money Maker the ###
  • Confirm Zelle business tag · FILE IT (EIN → DBA)
  • Authorize SEND 1–4 · pick up boxes from PMB
  • Keep Dual Plan A: ≥3 job apps first

ME (Money Maker)

  • Draft quotes · CS-IDs · packing checklist
  • Never invent deposits or SEND counts
  • Keep site/pricing synced · scoreboard honest
  • Ask you only for final send / FILE IT / BUY IT
